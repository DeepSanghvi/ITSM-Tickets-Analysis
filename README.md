# ITSM Ticket Analysis Dashboard
## Overview

This project analyzes IT Service Management (ITSM) ticket data to identify operational inefficiencies, SLA risks, and support trends.

The analysis focuses on:
- Ticket volume trends
- SLA compliance
- Resolution performance
- Reopened tickets
- Team efficiency

- ## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Tableau
- GitHub

- ## Dataset

Source: Kaggle ITSM Dataset

The dataset contains IT support ticket information, including:
- Ticket priority
- Resolution time
- SLA status
- Assignment groups
- Ticket categories

- ## Data Cleaning

Performed:
- Missing value handling
- Duplicate removal
- Datetime conversion
- Feature engineering
- KPI creation

- ## Key KPIs

- Total Tickets
- Average Resolution Time
- SLA Breach %
- Reopen Rate
- Ticket Volume by Category

## Insights

- Software issues generated the highest ticket volume
- SLA breaches were highest during weekends
- Network-related tickets had the longest resolution time
- High-priority tickets received significantly faster responses
